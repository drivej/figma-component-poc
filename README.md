# Figma component proof of concept

A deliberately small React/Vite project for testing repository import and code-layer rendering in Figma Design. It uses one reusable AccountSummary component in a simple two-card layout.

The figures and account labels are fictional sample data. There are no API calls, environment variables, Git-based dependencies, or component-library dependencies.

## Run locally

    npm install
    npm run dev

## Production build

    npm run build

The root index.html and npm run build script are intentionally conventional to keep the Figma setup surface minimal.
